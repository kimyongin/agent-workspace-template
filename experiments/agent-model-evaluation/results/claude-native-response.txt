### Defect 2 — `expectedRevision` guard is a TOCTOU race, not an atomic CAS

**Line 5:** `if (task.revision !== expectedRevision) throw new Error('conflict');`

### Defect 3 — Update and activity-log write are not atomic

### Defect 4 — Return value is a stale pre-write revision, not the persisted new revision

**Line 8:** `return { ...task, status: 'done' };`

**Contract:** the function must return the newly persisted revision value.

**Reality:** `task` was fetched before any write. Spreading it yields `revision: task.revision` (the *old* value), not `task.revision + 1` that was actually written. Any caller using the returned value for a subsequent optimistic-concurrency call will get a spurious conflict immediately.
