Resume marker: **ORCHID-527**

Four defects from the child agent's review of `review.mjs`:

1. **Owner-only check absent** — the function never compares `actorId == ownerId`; any actor can mutate any task they do not own.

2. **`expectedRevision` guard is a TOCTOU race** — the revision check on line 5 is against an in-memory snapshot; no atomic compare-and-swap is passed to the storage layer, so a concurrent write between `db.get` and `db.update` is silently lost.

3. **Update and activity-log write are not atomic** — lines 6 and 7 are two separate sequential `await` calls with no transaction; a crash between them leaves the document updated but the audit log missing.

4. **Return value carries stale revision** — line 8 spreads the pre-write `task` object, so the returned `revision` is the old value, not the `task.revision + 1` that was actually persisted.
