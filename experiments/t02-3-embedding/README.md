# T02-3 — 한국어 임베딩 품질과 입력 경계

Pinecone Inference의 독립 임베딩 호출로 `llama-text-embed-v2`와 `multilingual-e5-large`를 비교한다. 앱 코드·운영 DB·Pinecone 인덱스를 쓰지 않는다. Node 22 이상만 필요하고 설치할 의존성은 없다. 결과와 판단은 [Template-02 T02-3](../../docs/tickets/template-02-implementation-base.md#t02-3--사용자-원칙rag지식-연결)에 기록한다.

## 준비·실행·정리

1. 이 폴더의 `.env.local`에 `PINECONE_API_KEY=...`를 넣는다. 실제 키는 채팅·Git에 넣지 않는다. CLI 사용자 로그인만으로는 `/embed` 호출 키가 설정되지 않는다. 키 발급 명령은 설치된 `pc api-key create --help`에서 확인한다.
2. 저장소 루트에서 `npm run test --prefix experiments/t02-3-embedding`으로 오프라인 평가기 검증을 한다.
3. `npm run evaluate --prefix experiments/t02-3-embedding`으로 실제 모델을 호출한다. 모델 두 개에 각 9 HTTP 요청(메타데이터 1·정상 임베딩 7·상한 거부 1)을 한다. 성공 응답의 token 사용량을 출력한다. 호출 비용·계정 한도가 적용되므로 반복 호출은 필요한 경우에만 한다. 자동 재시도는 없다.
4. 결과는 Git 제외 `results.local.json`에 저장한다. 비밀과 벡터는 저장하지 않으며 예제 질문·점수·메타데이터·사용량만 기록한다. 중간 실패 시 완료한 모델의 결과를 보존한다. 환경값 누락·공급자 실패·초기 후보의 평가 실패는 종료 코드 1이다.
5. 정리는 이 폴더의 `.env.local`과 `results.local.json`을 삭제하면 된다. 외부 인덱스나 서버는 생성하지 않는다. 키 폐기는 별도 작업이며 공유 사용 중인 키를 자동 삭제하지 않는다.

## 평가 방식과 한계

- 한국어 예제 원문 10개. 제목+줄바꿈+요약만 passage로 보내고 본문은 보내지 않는다.
- 보정 질의 10개(관련 5·무관 5)로 cosine 임계값을 고른다. 관련 정답의 최저 점수와 무관 질문 최고 점수 사이에 틈이 없거나 정답이 1위가 아니면 채택하지 않는다.
- 별도 검증 질의 10개(관련 5·무관 5)는 임계값 선택에 쓰지 않는다. 관련 정답 1위·기준 이상, 무관 결과 기준 미만을 모두 요구한다.
- 본문 전용 식별 문구 3개는 의미 검색의 한계를 관찰하고 본문 키워드로 확인한다. 이 관찰은 실제 DB 키워드 검색 검증을 대신하지 않는다.
- 100+300 Unicode 코드 포인트의 한글·이모지·결합문자·무공백과 200자 질의를 절단 없이 호출한다. 10,000자 초과 입력은 공급자의 입력 한도 오류로 거부돼야 한다. 단순 400 응답을 입력 한도 거부로 세지 않는다.
- 같은 모델·차원 1024, passage/query 입력 종류, `truncate: NONE`, API 버전 `2026-07`을 고정한다. metadata의 차원·절단 지원과 반환 벡터의 모델·종류·개수·차원·유한 수치를 검사한다.

자료는 실제 사용자 기록이 아닌 예제다. 작은 평가를 통과했다고 모든 한국어·모든 도메인에서 재현율과 무관 질문 거부를 보장하지 않는다. 새 앱은 자료·질의를 해당 도메인으로 바꾸고 보정과 별도 검증을 다시 수행한다. UTF-8 byte·코드 포인트·모델 token은 다른 단위이며, 이 경계 샘플의 성공을 모든 가능한 문자열의 보장으로 확대하지 않는다.

2026-10-03 실행 결과는 [results-20261003.json](results-20261003.json)에 보존한다. 다시 실행해도 이 기록을 자동 덮어쓰지 않는다.

## 공식 근거

2026-10-03 확인: [llama 모델](https://docs.pinecone.io/models/llama-text-embed-v2), [e5 모델](https://docs.pinecone.io/models/multilingual-e5-large), [독립 임베딩 API](https://docs.pinecone.io/reference/api/2026-07/inference/generate-vectors). 실제 metadata도 결과 파일에 보존한다. 공식 문서의 일반 성능 주장을 이 실험의 검증 결과로 취급하지 않는다.
