# 보존 자료 읽기

현재 값은 엔터티·할 일·현재 원칙에서 확인한다. 과거 이유는 일반 기록과 변경 기록의 본문에서 찾는다. 과거 원칙 ID는 현재 문서 상세 링크로 사용하지 않는다.

과거 기록의 `applied_principle_snapshots`는 읽기 전용 원문이다. `captured_at=application`은 당시 연결 시점의 캡처, `migration`은 이관 당시 캡처이며 과거 실제 적용 시각을 보증하지 않는다. 원칙의 이후 변경·삭제나 메모 편집이 이를 현재 값으로 바꾸지 않는다. 새 참고는 필요한 경우 기록 본문으로 설명한다.

삭제된 대상의 `entity_context`는 캡처된 ID·이름·시점·출처다. `source=legacy_backfill`은 전환 당시 이름이며 당시 실제 이름을 보증하지 않는다. 이 문맥은 현재 대상 존재나 접근 권한의 근거가 아니다.

이관 보존 기록은 관리자 컷오프 캡처다. 본문의 원본 시각과 캡처 시각을 구분한다. `origin=legacy`와 `legacy_context`를 새 현재 원칙의 조건으로 재해석하지 않는다.
