# 보존 자료 읽기

현재 값은 자료·할 일에서 확인한다. 과거 이유는 수행 결과와 변경 기록의 본문에서 찾는다. 과거 계약으로 보관된 일반 기록과 before/after는 당시 근거로 읽으며 현재 작성 기능이나 최신 상태로 해석하지 않는다.

현재 기록의 부모는 같은 워크스페이스의 `entity_id` 또는 `task_id` 하나이며 생성 후 바뀌지 않는다. 소프트 삭제된 부모와 그 기록도 부모의 현재 권한으로 읽는다. 기록의 당시 이름·사건 정보와 보관된 작성자 이름은 현재 대상의 존재·상태·접근 권한을 보증하지 않는다.

할 일의 `entity_context`는 선택한 참고 자료의 당시 ID·이름·시점·출처다. 현재 자료 종류 읽기 권한으로 허용된 문맥만 사용하고 숨겨진 연결의 존재나 개수를 추측하지 않는다. 과거 계약의 기록 문맥도 역사 자료이며 현재 기록의 부모를 추가하거나 바꾸는 근거로 사용하지 않는다. `source=legacy_backfill`은 전환 당시 이름이며 사건 당시 이름을 보증하지 않는다. 완료·회차 결과는 할 일의 참고 자료 문맥을 상속하지 않는다.
