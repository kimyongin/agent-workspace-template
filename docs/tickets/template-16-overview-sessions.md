사용자는 컨텍스트 설명도 추가하도록 지시했다. 대화 내용·작업 자료라는 짧은 정의와 여러 작업 정보가 섞일 수 있어 필요한 자료를 선별 전달한다는 이유를 함께 반영한다. 토큰·창 크기·기억 보장·완전 초기화·분할로 모든 맥락 문제 해결을 주장하지 않는다.
