## 작업과 완료 조건

- [ ] 기록을 업무 시간대 날짜별로 묶고 동일 날짜 페이지 병합·중복 제거·접힘/복귀 유지. 검색/할 일에는 날짜 그룹 강제하지 않음.
- [ ] 활동/원칙 목록의 제목 선택·복사와 명시적 보기·편집 제공. 실제 이동 링크·대상별 접근성 이름. 직접 편집 취소/저장 후 진입 문맥 복귀.
- [ ] 활동/원칙 상세를 제목→요약→필요 메타→본문→관련 대상으로 정리. 현재 원칙 연결은 당시 원칙 snapshot을 뜻하지 않음.
- [ ] 작성 필드 순서 정돈, 상시 필터 구획과 해제 제공. 기존 필드 검증·완료·중단·재개·멱등성·버전 충돌 유지.
- [ ] 저장 성공 뒤 재조회 실패는 저장 실패와 구분하고 조회만 재시도. 늦은 조회가 초안 덮어쓰지 않음.
- [ ] 페이지 추가→상세→편집/취소→복귀, 날짜 접기, 검색 원문 복귀, 오류·dirty·모달 키보드 회귀 검증.

## PR 분할과 담당

PR 하나 `codex/fin-ux-activity`. activity 세션이 activity/principles feature, 필요한 공통 읽기·태그 표시/선택 표현과 회귀를 소유한다. App/global CSS/TagsPage/EntityDetail은 다른 담당이다. 스타일은 별도 feature CSS로 작성해 전역 동시 편집을 피한다. 선행18-02의 목록 삽입 변경은 메인 통합 후 보존한다. 공유 통합 환경은 순차 담당 배정을 기다리고 unit/build는 독립 실행한다.
