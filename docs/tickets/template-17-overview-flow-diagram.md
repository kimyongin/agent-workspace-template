## 실행과 인계

큰 화면은 사람 상단·본 대화 중앙·구현/리뷰 아래 양쪽이다. 선은 노드의 다른 port를 사용하고 생성·보고를 실선/점선으로 구분한다. ① 구현 생성·자료 전달, ② 구현 결과 보고, ③ 그 결과 뒤 독립 리뷰 생성·검토 요청, ④ 리뷰 결과 보고, ⑤ 사람에게 취합한 결과 설명 순서를 라벨에 표시한다. 두 하단 노드가 같은 높이여도 동시 실행으로 설명하지 않는다. 작은 화면은 사람·허브·구현·리뷰 순서이며 필요한 글자가 축소되지 않도록 별도360폭 viewBox를 쓴다. 화면 중복 SVG는 각자의 고유 접근성 ID를 가지며 보이는 그림 하나만 접근성 트리에 노출한다.

### 독립 리뷰 수정 — 중간 화면 가독성

독립 리뷰는 첫 인계 `1a15706079fac8bbdc0b369b1bac9cd819c0c756`에서 760/768px가 넓은 그림으로 전환되어 설명 글자가 약 10px로 축소되는 P2를 발견했다. 그림의 세로 배치 전환을 1023px 이하로 넓히고 넓은 배치의 설명 기본 글자를 14px로 맞췄다. 다른 그림·앱·분류 규칙은 변경하지 않는다.
