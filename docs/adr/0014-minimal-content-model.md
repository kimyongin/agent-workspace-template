# ADR-0014: 요약 제거와 본문 하나로 쓰는 기록

- 상태: 채택, 구현 전
- 날짜: 2026-10-07
- 근거: 모델 속성 간소화에 대한 대화와 빈 변경 메모에는 기본 변경 설명을 남긴다는 사용자 답변. 구현 범위와 진행 상태는 [#166](https://github.com/kimyongin/agent-workspace-template/issues/166)이 소유한다.

템플릿 사용자가 제목·요약·본문과 별도의 변경 기록을 반복 작성하는 부담을 줄인다. 할 일과 원칙의 사용자 내용은 제목·본문으로, 일반·결과·변경 기록의 사용자 내용은 본문 하나로 통일한다. 엔터티에는 현재 예제 업무 속성을 유지한다. 기록의 ID·버전·시각·사건 식별정보와 필요한 관계는 본문과 구별되는 시스템 정보다.

업무 변경 시 입력한 메모가 있으면 그것만 기록 본문으로 저장한다. 비어 있으면 확인 가능한 사실로 기본 변경 설명을 생성한다. 별도의 기록 제목·요약·본문 확인 단계를 거치지 않고 한 번에 저장하며 업무 변경과 기록은 같은 트랜잭션에서 확정한다. 삭제 의사 확인, 미저장 변경 보호, 같은 ID/version 재시도 의미는 유지한다. 기록 자체의 편집은 추가 로그를 만들지 않는다.

임베딩할 대상과 입력 텍스트, 긴 본문 처리 방식은 재검토 중이며 미정이다. 이전에 적은 '할 일·원칙은 제목, 기록은 본문' 정책과 길이 초과 시 의미 색인 제외·자동 요약/분할 미도입은 에이전트가 추론한 사항으로, 확정 결정에서 철회한다. 사용자 모델의 요약 속성 제거와 검색 입력의 선택은 구분해서 결정한다. 기록 목록의 대표 문구는 본문에서 표시용으로 계산하며 별도 제목·요약 속성으로 저장하지 않는다.

ADR-0012의 기록 제목·요약·본문 및 저장 전 메모 확인 규칙을 이 결정으로 대체한다. ADR-0004를 대체할 검색 입력 정책은 미정이다. 소유자 격리·트랜잭션·큐·현재 상태와 통합 기록의 책임은 유지한다. 기존 제목·요약 중 본문에 없는 내용은 후속 migration에서 보존하고 폐기한 입력과 미리보기 인터페이스는 남기지 않는다. 이 결정 기록은 코드 전환이나 DB 적용 완료를 의미하지 않는다.
