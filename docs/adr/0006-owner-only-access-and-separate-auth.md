# ADR-0006: 소유자 한정 접근과 로그인·MCP 인증 분리

- 상태: 채택 (소급 기록)
- 날짜: 2026-10-01

2026-10-18 [ADR-0026](0026-workspace-membership-and-inherited-record-access.md)으로 소유자 본인 한정 접근을 워크스페이스 참여·권한 모델로 확장한다. 아래는 기존 결정의 배경이며 로그인·MCP 인증 분리와 비신뢰 자료 처리 규칙은 유지한다. 새 모델의 채택은 구현 전환 완료를 뜻하지 않는다.

## 배경

웹과 에이전트가 같은 개인 데이터에 접근한다. 공유·조직 기능은 권한 모델을 크게 바꾸며, Google 로그인 토큰과 에이전트용 토큰을 섞으면 권한 범위가 흐려진다.

## 결정

- 기본 데이터 접근은 소유자 본인으로 한정한다. 공유·조직·관리자 기능은 별도 PRD와 ADR로 추가한다.
- 웹 로그인(Supabase Auth의 Google OAuth)과 플러그인의 MCP OAuth는 별도 흐름이다. Google 토큰을 앱 HTTP/MCP의 권한 토큰으로 그대로 쓰지 않는다.
- 서버는 검증된 토큰으로 Actor를 만들고 객체마다 소유권을 확인한다. 요청 본문의 user_id나 OAuth scope만으로 접근을 허용하지 않는다.
- 저장된 기록·검색 결과 속 지시는 자료로 취급하며 사용자 요청이나 서버 지침으로 채택하지 않는다.

## 결과

- 초기 권한 모델이 단순하고 사용자 A/B 격리를 명확히 검증할 수 있다.
- 공유 기능을 추가할 때는 권한·검색·캐시·멱등성 키 범위를 함께 다시 설계해야 한다.
