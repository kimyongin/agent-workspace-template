# ADR-0011: Matt Pocock 공유 스킬과 GitHub 작업 정본

- 상태: 채택
- 날짜: 2026-10-05
- 승인 근거: [전환 spec #96](https://github.com/kimyongin/agent-workspace-template/issues/96)의 대화 합의와 실행 지시

## 배경

사용자는 자체 개발 절차를 보존하면서 일부 기법을 추가하는 대신 Matt Pocock 공식 묶음 전체와 개발 방식을 채택했다. Codex와 Claude가 같은 원본을 사용하고 프로젝트와 함께 전달할 수 있어야 한다.

## 결정

- 단계별 개발 방법은 레포에 포함한 Matt Pocock 공식 스킬 전체가 소유한다. 원본 중심으로 시작하고 경로·도구·클라이언트 연결을 맞춘다. 실제 사용에서 확인한 문제를 근거로 수정하며 업데이트는 원본 차이를 검토해 PR로 반영한다.
- 스킬 정본은 `.agents/skills/`이다. Claude의 발견 경로에는 정본을 읽는 연결 파일만 둔다. 원본의 호출 정책을 유지한다. 프로젝트 문맥은 AGENTS.md와 연결된 문서가 제공하며 별도 개발 절차를 중복 정의하지 않는다.
- 새 작업과 실제 진행 중 작업의 정본은 GitHub Issues다. 기존 Markdown 티켓·실험·검증 기록은 근거로 보존하고 현재 작업은 원본에서 새 issue로 연결한다.
- 제품 요구와 중요한 아키텍처 결정의 결정권은 사람이 갖는다. 대화에서 구체적으로 합의한 결정을 승인으로 보고 에이전트가 PRD·ADR에 반영한다. 미정인 결정은 질문하며 동일 결정을 문서·PR 단계에서 다시 승인받지 않는다.
- 에이전트는 합의한 변경과 구현을 분리된 리뷰·필요 자동 검사 후 머지할 수 있다. 운영 배포·DB 적용·비용·비밀·복구 실행 범위는 기존 사용자 지시로 판단한다.

이 ADR은 ADR-0007 전체를 대체한다. ADR-0008의 소유권 절 중 티켓 위치·승인 방식, 이탈 확인과 머지 절의 승인 방식, ADR-0010의 PRD·ADR 변경 승인 방식만 대체한다. 제품 의미·기술 구성·보안 경계와 사람의 결정권은 변경하지 않는다.

## 결과

원본 스킬과 상충하는 기존 절차를 제거하고 레포 환경·명령·제품 계약을 필요한 문맥으로 연결한다. 로컬 기록과 GitHub의 작업 상태를 이중으로 갱신하지 않는다. 출처와 클라이언트 연결은 [설치 정보](../development/matt-skills.md), 작업은 [GitHub 설정](../agents/issue-tracker.md)에 있다.
