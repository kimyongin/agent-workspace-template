# ADR-0013: 실제 사용처를 기준으로 미사용 계약 제거

- 상태: 채택
- 날짜: 2026-10-06
- 승인 근거: 사용자가 #134의 대기 사유를 확인한 뒤 별도 외부 사용처가 없으며 레거시 인터페이스를 제거하고 지침에 반영하도록 지시했다.

## 배경

통합 기록 모델로 앱의 계약을 전환하면서 이전 버전의 외부 사용 가능성을 이유로 구 인터페이스를 유지했다. 사용자는 현재 앱 이외의 별도 사용처가 없다고 확인했다. 확인되지 않은 호환 요구를 계속 유지하면 새 계약과 사용하지 않는 구 계약이 함께 쌓인다.

## 결정

구 계약의 지원 여부는 실제 사용처로 판단한다. 앱 내부 호출자는 새 계약으로 함께 전환하고 미사용 인터페이스를 제거한다. 실제 외부 사용처가 있을 때만 지원 대상과 종료 조건을 명시해 임시 호환을 유지한다. 상세 개발 기준은 [코드 설계 원칙](../architecture/principles.md#9-실제-사용처를-기준으로-구-계약을-정리한다)이 소유한다.

구 인터페이스 제거는 기존 기록의 삭제를 뜻하지 않는다. 보존된 자료는 새 계약으로 조회하며 운영 DB 적용·서비스 배포는 별도 지시 범위를 따른다.

## 결과

지원하는 계약과 실제 사용처가 일치하고, 구 입력과 임시 호환 코드의 정리를 변경 작업 안에서 완료한다. 제거된 계약을 사용하는 이전 버전은 더 이상 지원하지 않으므로 실제 사용처가 생기면 해당 앱의 전환 계획을 먼저 정한다. 현재 제거 범위와 검증·머지 상태는 [#134](https://github.com/kimyongin/agent-workspace-template/issues/134)에서 관리한다.
