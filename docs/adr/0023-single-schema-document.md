# ADR-0023: 자료 종류 정의를 단일 JSON Schema 문서로 관리

- 상태: 채택, 구현·검증은 [스펙 #468](https://github.com/kimyongin/agent-workspace-template/issues/468)
- 날짜: 2026-10-16
- 승인 근거: 종류·속성·표시 설정의 단일 문서화, 표준 키 우선, import/export와 2개 통합 티켓에 대한 대화 합의

자료 종류를 파일 하나로 내보내고 같은 종류에 다시 적용하기 위해 종류 이름·아이콘·보관 상태와 속성 정의·표시 설정을 Draft 2020-12 문서 하나에 둔다. ADR-0020의 별도 schema/display와 metadata/schema 버전 분리를 이 결정으로 대체한다. 속성 키 불변·소유권·불변 게시·원자적 값 변환·복구의 기존 보장은 유지한다.

## 정의와 게시

루트의 `x-type-id`는 종류의 불변 ID, `x-version`은 서버가 발급하는 게시 번호다. `$schema`는 JSON Schema 규격을 식별하며 업무 버전이 아니다. 루트 `title`·`description`·`x-icon`·`deprecated`는 종류의 이름·설명·아이콘·보관 상태다. 필수 `x-title-template`은 속성 변수와 일반 문자를 조합하는 자료 제목 정의다. 각 속성에는 표준 타입·제약·기본값·설명과 `x-order`·`x-search-text`를 직접 둔다. 별도 확장 객체나 표시 설정 사전을 정본으로 저장하지 않는다. 입력·키–값 상세의 속성 순서는 `x-order`를 따른다.

선택지는 문자열 코드와 선택적 null의 `oneOf`/`const`/`title`로 값·이름·순서를 함께 표현한다. 표준 `deprecated`·`readOnly`·`default`·`examples`의 의미를 앱이 명시적으로 처리하며, annotation 자체가 입력 제한이나 기본값 적용을 실행한다고 보지 않는다. 일반 조합·중첩·외부 참조를 지원하는 범용 스키마 엔진으로 확대하지 않는다. 정의 문서는 표준 선택지와 annotation의 표현 비용을 포함해 256 KiB를 허용하고 자료 속성값은 기존 64 KiB를 유지한다. 같은 설정의 표준 표현이 커져도 기존 유효 정의를 손실 없이 전환하기 위한 한도 조정이다. 실제 지원 집합과 나머지 자원 한도는 공유 계약이 소유한다.

이름·아이콘·보관·속성의 실제 변경은 모두 새 스키마 게시 버전이다. 무변경에서는 새 버전을 만들지 않는다. 보관 종류의 해제와 메타데이터 변경도 이 게시 경로에서 가능해야 하며 소유권·경쟁·작업 잠금은 동일하게 적용한다. 현재 포인터, 자료의 마지막 저장 정의 버전, 자료 데이터 버전, 변경안/작업 버전, 요청 키는 각자의 역할을 유지한다.

## 저장과 보존

게시 정의 테이블은 소유자·종류 ID·스키마 버전·전체 JSONB 문서·게시 시각을 가진다. 종류 ID와 버전은 문서에서 추출하는 저장 생성 컬럼으로 유일성·외래키·권한 검사를 지원한다. 종류 테이블은 ID·소유권·현재 포인터·속성 번호 발급과 작업 잠금 등 관리 정보를 유지한다. 이름·아이콘·보관 상태·display의 독립 저장은 실제 사용처를 전환한 뒤 제거한다.

전환 전 과거 정의의 속성·표시·버전은 보존하되 없는 당시 종류 메타데이터를 추정하지 않는다. 현재의 완전한 문서를 새 버전으로 게시하고 그 이후부터 전체 문서 이력을 보장한다. 진행 중 변경안·분석·작업과 완료 요청의 재현, 완료 작업의 원본 복구는 각각 기존 결속·기한을 보존한다. 값 복구는 이후 수정한 종류 이름·아이콘·설명·보관 상태를 과거로 되돌리지 않는다. 전환 전 입력은 30일 보존 중인 성공 요청의 정확한 재확인에만 허용한다. 원래 작업·정규화 입력·대상·요청 키의 fingerprint가 일치하는 기존 결과를 읽으며, 보존 결과가 없으면 구 입력으로 새 쓰기를 실행하지 않는다. 이 경계는 구 쓰기 인터페이스가 아니며 마지막 전환 전 요청의 보존 기간이 끝나면 제거할 수 있다.

## 가져오기

같은 소유자의 `x-type-id`가 기존 종류를 식별한다. 파일의 `x-version`은 원본 버전이며 최신값 덮어쓰기 권한이나 새 게시 번호를 부여하지 않는다. 현재 정의 대비 차이와 영향을 검토한 새 변경 의도를 기대 버전과 요청 키에 결속해 정상 게시 또는 기존 값 변환으로 적용한다. 새 종류로 복사하는 경우 서버가 새 ID·초기 버전·속성 키를 발급하고 대응을 보여준다. 자료 값·발급처·태그·개인 설정의 이식은 별도 범위다.

파일과 텍스트는 같은 원문 파서를 사용하며 중복 객체 키와 미지원 키를 위치와 함께 거부한다. 미리보기는 속성 번호를 예약하지 않는다. 기존 종류의 준비는 검토한 현재 버전과 키 대응을 결속해 일반 변경안으로 저장한다. 새 종류 복사는 하나의 쓰기에서 새 ID와 전체 정의를 함께 만든다. 소스에 빠진 기존 속성은 삭제 후보로 표시하고 명시 확인 및 기존 영향 분석을 거친다. 검증된 전환 전 역사 문서만 빠진 종류 메타데이터를 현재 값으로 유지하며, 근거 없는 불완전 문서는 사용자 보완을 요구한다.

## 대가

종류 이름이나 아이콘 변경도 게시 이력과 스키마 경쟁에 참여한다. 데이터가 변하지 않는 변경까지 스키마 버전이 증가하지만, JSON 하나가 해당 시점의 전체 정의를 설명하고 import/export가 같은 계약을 사용한다. 전환 중 실제 보존 자료를 읽는 변환은 유지할 수 있으나 독립된 구·신 쓰기 정본을 운영하지 않는다. 운영 배포·DB 적용은 별도 사용자 지시 범위다.

## 제목 템플릿 전환

2026-10-21 사용자 합의와 [스펙 #538](https://github.com/kimyongin/agent-workspace-template/issues/538)에 따라 대표 속성·목록 표시 선택을 제목 템플릿으로 대체한다. 화면은 현재 속성 이름을 변수 칩으로 보여주고 저장 문법은 `$prop_n$`을 사용한다. 속성 이름 변경은 연결을 바꾸지 않는다. `$$`는 달러 문자이고 기존 기록 편집기의 `${prop_n$}` 입력도 해석한다. 표현식·HTML·관계 참조를 실행하지 않는다.

현재 자료의 목록·검색·선택·연결·상세와 HTTP/MCP는 같은 계산 제목을 사용한다. 제목에 참여한 속성도 펼친 키–값에서 읽을 수 있다. 미입력/null은 빈 문자열로 표시하되 null 선택 이름이 있으면 그 이름을 사용한다. 숫자 0과 거짓을 누락하지 않으며 공백뿐인 결과는 자료 식별자로 대체한다. 템플릿과 결과는 기존 텍스트 범위인 Unicode 코드 포인트 4,096자 안에서 처리하고 긴 결과는 4,095자 뒤 말줄임표로 표시한다.

기존 현재 정의는 대표값을 참조하는 템플릿을 가진 새 불변 버전으로 게시한다. 원래 자료 값·저장 정의 버전·자료 버전·태그·관계와 확정된 과거 기록·요청 결과·fingerprint는 보존한다. 이전 문법은 과거 정의 읽기와 정확한 완료 요청 재현 경계에서만 해석하고 새로운 쓰기에는 허용하지 않는다. 진행 중인 변환·분석은 이관이 임의로 취소하거나 재작성하지 않는다.


최종 활성 계약은 루트 `x-title-template`을 필수로 요구하고 속성의 `x-representative`·`x-show-in-list`·`x-list-order`와 요약의 `display_properties`를 받지 않는다. 새 종류의 `initial_property_label`은 일반 최초 이름 속성의 라벨이며 제목을 위한 특별 제약을 만들지 않는다. 전체 모델 복사는 속성 키와 템플릿 참조를 함께 대응시킨다. 복구는 현재 템플릿을 보존하고 복구안에서 사라지는 참조가 있으면 현재 템플릿을 먼저 수정하도록 안내한다.

이관은 짧은 잠금 제한과 전체 대상 사전 검증을 가진 단일 트랜잭션이다. 공간에 속한 현재 정의만 필요할 때 현재+1 버전으로 게시한다. 구성한 템플릿이 있으면 유지하며 이미 깨끗한 정의와 공간 미배정 과거 행은 그대로 둔다. 활성 분석·변환·전체 모델 작업 또는 종류 쓰기 잠금이 있으면 아무 변경 없이 중단한다. 기존 작업·초안·원본·receipt·fingerprint·기한은 재작성하지 않는다. 과거 검토는 새 현재 포인터와 달라져 정상적인 재검토가 필요하며 새 변경안으로 다시 시작한다. 제목만 바뀐 게시로 선택 텍스트의 색인을 다시 요청하지 않는다.
