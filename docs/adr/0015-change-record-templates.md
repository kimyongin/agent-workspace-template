# ADR-0015: 변경 기록 템플릿과 사용자 업무 설정

사용자 원칙과 그 보존 계약은 [ADR-0022](0022-remove-user-principles.md)로 대체되었다. 아래의 해당 부분은 당시 결정의 배경이다.
- 상태: 채택
- 날짜: 2026-10-09
- 근거: 웹과 에이전트에 같은 템플릿을 적용하고 잘못된 템플릿 저장을 거부하자는 대화 합의, [#242](https://github.com/kimyongin/agent-workspace-template/issues/242)

변경 기록의 기본 설명을 사용자의 업무에 맞추기 위해 모델·액션별 메모 템플릿과 기본 기록 태그를 사용자 업무 설정으로 관리한다. 웹과 MCP는 같은 검증·해석 규칙을 사용하고, 명시한 메모와 태그를 자동 기본값보다 우선한다. 기록 자체의 작성·편집은 추가 기록을 만들지 않는 기존 규칙을 유지한다.

업무 설정은 하나의 테이블 안에서 소유자·설정 ID별 JSON 값과 버전으로 저장한다. 기록 기본값(`record_templates`)과 엔터티 식별자(`entity_identity`)는 각각 독립된 저장 단위이며 요청은 해당 ID·expected_version·value를 전달한다. 다른 ID의 저장은 버전을 바꾸지 않고, 같은 ID에 먼저 저장된 변경이 있을 때만 충돌로 처리한다. 기존 묶음은 값·버전을 보존해 두 행으로 이관한다. 권한이나 비밀값을 담지 않고, 프로필·화면 표시용 Auth metadata와 책임을 나눈다. 새 업무 설정마다 테이블을 추가하지 않으며 저장 경쟁으로 다른 설정을 덮어쓰지 않는다.

같은 설정 ID의 충돌은 속성별로 자동 병합하지 않는다. 최신값을 읽어도 미저장 초안을 통째로 보존하고 충돌 상태를 유지하여, 오래된 초안을 새 버전으로 저장하지 못하게 한다. 사용자가 ‘최신값으로 다시 편집’을 선택하면 읽어온 설정을 초안에 적용하고 충돌을 해제한다. 이후 필요한 내용을 다시 편집하여 최신 expected_version으로 저장한다. 미저장 변경이 없는 일반 읽기는 최신값을 그대로 적용한다. 이 흐름은 발급처와 기록 템플릿에 동일하게 적용하며 속성별 버전이나 별도 테이블을 추가하지 않는다. 근거: 설정 ID·버전으로 단순하게 처리하자는 대화 합의, [#318](https://github.com/kimyongin/agent-workspace-template/issues/318).

템플릿은 제한된 변수 치환만 제공한다. 생성의 이전 값·삭제의 이후 값처럼 존재할 수 없는 변수, 알 수 없는 속성과 잘못된 구문은 위치·이유를 설명하고 저장을 거부한다. 입력 초안과 이전에 저장한 설정은 보존한다. 업무 속성의 전체 이전 값과 최종 이후 값으로 기본 메모를 만들며, 사용자 메모는 자동으로 확대하거나 다시 작성하지 않는다. 기록 태그는 기록용 사전의 기존 태그를 선택한다.

설정 변경은 과거 기록이나 결과가 불확실한 저장 시도의 내용을 다시 쓰지 않는다. 기본값을 준비한 뒤 ID·버전·업무 입력·메모·태그를 고정해 같은 요청으로 재시도한다. 웹 확인 단계는 사용자 수정과 기본값을 구별하며 메모·태그 각각의 입력을 보존한다. 핵심 기능과 검증 상태는 [#243](https://github.com/kimyongin/agent-workspace-template/issues/243)과 연결된 PR에서 확인한다.

사용자 메모 템플릿이 없거나 비어 있으면 등록·삭제·복원·중단·재개는 기본 템플릿 `$대상$ $액션$`, 수정은 `$대상$ $액션$ ($변경항목$)`을 사용한다. 설정 화면에도 같은 기본 템플릿을 실제 입력값으로 보여준다. 대상·액션·변경 항목은 각각 독립된 변수로 치환하며 설정에서 기본 문구 구조를 직접 편집할 수 있다. 기존 사용자 템플릿의 `${변경내용$}`은 호환을 유지한다. 기본값을 보여주는 것만으로 사용자 설정을 저장하거나 미저장 변경으로 처리하지 않는다. 사용자 템플릿과 기본 기록 태그는 그대로 우선하며, 메모가 비어 있는 기존 설정의 태그도 보존한다.

변수 구분자는 `$` 하나로 통일하며 `$대상$`, `$엔터티.이후.속성2$`처럼 작성한다. 달러 기호 자체는 `$$`로 표시한다. 기존 `${변수$}` 저장값도 해석하며 설정 화면과 새 변수 삽입은 새 구문을 사용한다. 표시 변환만으로 저장하지 않는다.

## 자료 종류별 기본 문구 단순화 (2026-10-13)

자료의 공통 템플릿 편집 설정은 제거한다. 자료 종류·행동별 `memo`가 null이거나 설정하지 않은 경우 고정 기본 문구를 표시하고 사용한다. 종류별 기본 기록 태그는 문구와 독립적이며 기본 문구로 되돌려도 보존한다. 종류별 사용자 문구는 활성 전용 속성 변수를 사용할 수 있고 자료 태그와 기록 태그는 서로 다른 사전이다. 자료 태그 관리는 설정의 다른 태그 관리 옆에, 발급처·식별자 설정은 일반 설정의 독립 섹션에 둔다.

이전 저장값의 공통 자료 템플릿은 읽을 때 무시하고 종류별 빈 문구는 null로 해석한다. 읽기만으로 저장값·버전을 변경하지 않고 새 쓰기는 제거된 공통 키를 거부한다. 과거 기록·업무 자료의 데이터 변환은 없다. 값 변환 작업의 내부 확정 템플릿 snapshot 형식은 유지하며 유효 문구 비교도 같은 고정 기본값 규칙을 따른다. 근거: 사용자 대화 합의, [#390](https://github.com/kimyongin/agent-workspace-template/issues/390).
