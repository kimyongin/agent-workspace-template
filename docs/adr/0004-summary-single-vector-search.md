# ADR-0004: 제목+요약 단일 벡터 검색

- 상태: 대체됨 — [ADR-0014](0014-minimal-content-model.md) (소급 기록)
- 날짜: 2026-10-01

이 문서는 과거 결정의 이력이다. 현재는 기록 본문 구간 검색을 사용하며 제목·요약 입력과 단일 벡터 정책은 적용하지 않는다.

## 배경

쌓인 할 일·기록·원칙을 다음 업무에서 찾아 쓰는 RAG가 제품의 핵심이다. 본문을 청크로 나누면 색인·갱신·점수 병합이 복잡해지고, 서버에 요약 LLM을 두면 비용과 운영 요소가 늘어난다.

## 결정

- 사용자나 외부 에이전트가 작성한 제목과 요약을 하나의 입력으로 임베딩하고 항목당 현재 벡터 하나를 유지한다.
- 본문은 청킹·자동 절단하지 않고 보존하며 키워드 검색과 원문 상세 조회에 사용한다.
- 서버 내부 자동 요약 LLM을 기본 구성에 두지 않는다. 요약 작성 방법은 웹 입력과 제품 스킬이 안내한다.
- 검색 결과는 원본 상세로 이어지고 원본과 같은 권한을 적용한다. 결과 없음·색인 지연·검색 장애를 구분한다.

## 결과

- 색인·갱신·재색인이 단순하고 본문만 바뀌면 재임베딩하지 않는다.
- 요약에 없는 본문 세부 내용은 의미 검색으로 찾기 어렵다. 키워드 검색과 원문 읽기로 보완하며 이 한계를 사용자·에이전트에게 숨기지 않는다.
