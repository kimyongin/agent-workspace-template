# ADR-0001: 헥사고날 구조와 HTTP·MCP 공통 유스케이스

- 상태: 채택 (소급 기록)
- 날짜: 2026-10-01

## 배경

사람은 웹으로, 외부 에이전트는 MCP로 같은 데이터와 업무를 다룬다. 두 진입점이 업무 규칙을 각자 구현하면 결과·권한·오류가 어긋난다. 에이전트용 스킬은 작업 방법을 안내할 뿐 실행을 강제하지 못한다.

## 결정

- 도메인과 유스케이스에 업무 로직을 두고 HTTP·MCP·Supabase·외부 서비스는 포트와 어댑터로 연결한다. core는 SDK·SQL·HTTP 요청 객체·환경변수에 의존하지 않는다.
- HTTP와 MCP는 같은 유스케이스를 직접 호출한다. 이름은 달라도 결과·권한·변경 범위·오류·재시도 의미는 같아야 한다.
- 권한·업무 규칙·데이터 일관성은 서버가 강제한다. 제품 스킬은 자료 탐색과 작업 순서를 안내하며, 스킬을 따르는지에 따라 보호 수준이 달라지지 않는다.
- 공통 구조는 실제 기능을 만들며 필요한 만큼만 만든다. 범용 payload 저장소·명령 엔진·가상의 여러 DB 지원을 선행 구축하지 않는다.

## 결과

- 업무 규칙을 DB 없이 테스트하고 두 진입점에서 일관되게 실행할 수 있다.
- 포트·어댑터 경계를 유지하는 비용이 들고, HTTP·MCP 동등성을 교차 테스트로 확인해야 한다.
