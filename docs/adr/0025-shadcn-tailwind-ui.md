# Tailwind와 공식 shadcn으로 UI 표현 계층을 전환한다

2026-10-17 사용자 합의에 따라 기존 디자인을 재현하는 점진적 혼용 대신 전체 웹 UI·디자인 샘플을 Tailwind v4와 공식 shadcn/ui로 전환한다. 컴포넌트를 적극적으로 조합해 새 화면과 AI 개발이 같은 구조·토큰·접근성 동작을 재사용하도록 한다. React·라우팅·업무 상태와 서버 계약은 유지한다. 추적은 [#499](https://github.com/kimyongin/agent-workspace-template/issues/499), 구현은 [PR #507](https://github.com/kimyongin/agent-workspace-template/pull/507)에서 관리한다.

공식 스킬은 원본을 고정 revision으로 설치하고 공식 CLI의 radix-nova·neutral 구성을 출발점으로 사용한다. 공식 레지스트리가 생성하는 부품의 내부 구현을 따른다. 현재 Combobox는 공식 Base UI 구현이며 다른 부품의 Radix 구성과 함께 사용한다. 생성 소스는 저장소가 소유하고 최소 44px 조작 영역 등 제품 접근성 기준을 공통 부품에서 적용한다. 화면마다 별도 테마·구 CSS 호환 별칭을 만들지 않는다. 차트는 공식 Chart/Recharts, 달력은 공식 Calendar, 작업 영역은 Sidebar·Resizable·Tabs로 구성한다.

개인 화면 배율, 같은 정보의 보기·편집, 태그 독립 연결, 확인 취소·응답 미확정의 초안 보호와 키보드/초점 계약은 보존한다. 기존 커스텀 UI를 유지하거나 직접 만드는 예외는 구현 전에 사용자에게 대상·이유·대안을 알린다. 이미 알린 예외는 템플릿 메모의 변수 칩·IME·선택·undo 편집 엔진이며 바깥 폼과 조작은 공식 부품을 쓴다. 공식 부품의 조합과 데이터·라우팅·배율 로직은 이 예외와 구분한다.

기존 흑연색·파란 강조·Pretendard·작은 보조 버튼의 구체적인 시각 지시는 새 디자인 문서로 대체한다. 원래 스크린샷은 역사적 근거이며 현재 구현 목표가 아니다. 문서 채택·소스 전환·전체 테스트·실제 캡처 검수는 별도 완료 상태로 기록하며, 이 결정은 운영 배포나 PR 머지 승인이 아니다.
