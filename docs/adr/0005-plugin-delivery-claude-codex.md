# ADR-0005: 에이전트 제공 단위는 플러그인, Claude·Codex 지원

- 상태: 채택 (소급 기록)
- 날짜: 2026-10-01

## 배경

MCP 도구만 연결하면 에이전트는 기능에 접근할 수 있지만, 어떤 자료를 먼저 찾고 원문을 어떻게 확인하며 결과를 어떻게 기록할지는 모른다. 사용자는 Claude와 Codex 계열 에이전트를 모두 사용한다.

## 결정

- 에이전트에게 제공하는 단위는 MCP 연결과 제품 스킬을 함께 묶은 플러그인이다. MCP 단독 연결 성공을 플러그인 완료로 보지 않는다.
- 지원 클라이언트는 Claude와 Codex다. 두 클라이언트는 같은 MCP 서버 계약과 같은 제품 스킬(`plugins/workspace/skills/workspace/`)을 사용하고, manifest·연결 설정·설치 절차만 클라이언트별로 둔다.
- 플러그인에는 서버 런타임과 비밀값을 넣지 않는다. 개발 스킬은 제품 패키지에 포함하지 않는다.

## 결과

- 클라이언트마다 설치·인증·스킬 동작을 따로 검증해야 하며 한쪽 결과로 다른 쪽을 통과 처리하지 않는다.
- 클라이언트별 manifest 형식은 공식 자료로 확인해 구현 티켓에서 정한다.
