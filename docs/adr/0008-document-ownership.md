# ADR-0008: 문서 소유권

- 상태: 채택
- 날짜: 2026-10-01
- 정리 승인: [#136](https://github.com/kimyongin/agent-workspace-template/issues/136)의 2026-10-06 합의

## 배경

사람은 제품의 목적과 중요한 구조를 결정하고, 에이전트는 합의한 범위의 개발을 진행한다. 결정 권한과 문서 작성자를 구분한다.

## 결정

| 대상 | 결정권 | 위치 |
| --- | --- | --- |
| 제품 의미·범위 | 사람 | [PRD](../product/concept.md) |
| 되돌리기 비싼 구조·기술·보안 경계 | 사람 | [ADR](README.md) |
| 티켓·구현·테스트·리뷰 | 에이전트 | GitHub Issues·PR과 코드 |
| 제품 가이드·스킬·환경 문맥 | 에이전트 | `docs/`, `.agents/`, `plugins/` |

에이전트는 PRD·ADR 초안과 합의한 변경을 작성한다. 대화에서 구체적으로 합의한 결정은 승인으로 보고 문서에 반영한다. 미정 결정과 승인 범위를 벗어나는 변경은 사람에게 확인하며, 이미 합의한 결정을 다시 승인받지 않는다.

## 결과

제품 의미는 PRD, 중요한 구조 결정은 ADR에 모인다. 가이드와 구현은 이 결정 안에서 발전한다. 개발 방법과 머지·운영 권한은 [ADR-0011](0011-matt-skills-and-github-workflow.md)이 담당한다.
