# ADR-0022: 판단 기준은 자료로 관리하고 사용자 원칙 기능 제거

- 상태: 채택
- 날짜: 2026-10-16
- 승인 근거: [#467](https://github.com/kimyongin/agent-workspace-template/issues/467)의 사용자 지시와 기존 내용도 삭제한다는 후속 합의

판단 기준을 일반 자료로 관리할 수 있으므로 사용자당 현재 문서 0~1개인 별도 사용자 원칙 모델을 제거한다. 전용 화면·검색 종류·기록 템플릿·HTTP/MCP·제품 스킬과 저장 계약을 함께 정리한다. ADR-0012·0013·0014·0015의 사용자 원칙 및 원칙 보존 부분은 이 결정으로 대체한다.

기존 원칙과 관련 변경 기록·적용 스냅샷·이관 보존 기록·검색 파생 데이터·저장 응답 복사본도 후속 migration으로 삭제하고 자료로 자동 이관하지 않는다. 일반 자료·할 일·직접 작성한 기록은 보존한다. 과거 보존 기록은 기존 이관기의 원본 종류·조각 번호·고정 출처 머리말로 식별하며 일반 본문의 단어로 삭제하지 않는다. 적용된 migration과 Git 이력은 실행 이력으로 유지한다. 운영 배포·DB 적용은 별도 지시 범위다.
