# ADR-0009: 리뷰는 필수, 다른 에이전트의 교차 리뷰는 선택

- 상태: 채택
- 날짜: 2026-10-02

## 배경

[ADR-0008](0008-document-ownership.md)의 머지 절은 "다른 에이전트의 교차 리뷰"를 머지 조건으로 정했다. 이 템플릿을 쓰는 프로젝트가 Codex와 Claude Code 중 하나만 사용할 수도 있는데, 그러면 교차 리뷰를 할 수 없어 머지 조건을 충족하지 못한다. 교차 리뷰의 목적은 구현한 맥락에 묶이지 않은 시각으로 결함과 PRD·ADR 이탈을 찾는 것이며, 다른 에이전트가 있어야만 이룰 수 있는 것은 아니다.

## 결정

- 모든 PR은 머지 전에 리뷰를 받는다. 리뷰는 구현한 작업 맥락과 분리된 리뷰어가 한다. 다른 개발 에이전트 또는 같은 에이전트의 새 세션이 리뷰어가 될 수 있다.
- 다른 개발 에이전트의 교차 리뷰는 권장하지만 필수가 아니다. 개발 에이전트를 하나만 사용하는 프로젝트도 이 템플릿의 절차를 그대로 따른다.
- PRD·ADR을 바꾸지 않고 벗어나지도 않는 변경은 리뷰 결론이 `머지 가능`이고 자동 검사를 통과하면 에이전트가 머지한다. PRD·ADR을 바꾸는 PR은 사람이 승인한다.
- 이 결정은 ADR-0008의 "머지" 절을 대체한다. ADR-0008의 나머지 결정은 유지한다.

## 결과

- 개발 에이전트를 하나만 써도 머지 조건을 충족할 수 있다.
- 같은 에이전트의 새 세션은 다른 모델의 시각을 주지 못한다. 두 에이전트를 모두 쓸 수 있으면 교차 리뷰를 우선한다.
- [ADR-0007](0007-dual-development-agents.md)의 공용 정본 구조는 그대로 유지하며, 한 에이전트만 써도 같은 지침과 스킬로 동작한다.
