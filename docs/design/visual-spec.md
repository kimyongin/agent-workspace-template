# 시각 규격

## 적용 방식

이 문서는 [디자인 가이드](guide.md)의 시각적 기본값을 정의한다. 공통 스타일 한 곳에 토큰과 의미별 클래스를 만들고 각 화면이 사용한다. 값마다 별도 React 컴포넌트나 범용 스타일 엔진을 만들 필요는 없다. 변경은 공통 정의에서 하고 소비 화면을 검수한다.

## 테마와 색

목록 보기 선택기는 텍스트 없는 13px 선 아이콘과 22px의 작은 표시 면을 사용한다. 선택 배경은 surface 토큰의 어두운 회색이며 파란 대표 행동 배경을 사용하지 않는다. 선택 아이콘은 accent 토큰의 파란색을 사용하고 hover 중에도 유지하며, 미선택은 보조 글자 색이다. 그룹 배경·외곽선·안쪽 여백 없이 아이콘을 연속 배치한다. 정밀 포인터에서는 각 버튼을 기본 28×28px(1.75rem, 최소 24px)로 줄이고 터치 등 정밀 포인터가 아닌 환경에서는 44×44px 조작 영역을 유지한다. 선택 배경과 키보드 초점으로 상태를 구별한다. 카드/테이블/캘린더도 같은 공통 토큰·본문 글자·작은 행동 규격을 따른다.

기본안은 C 시안의 불투명한 흑연색 배경과 파란 강조색이다. [승인한 C 시안](references/compact-dark-c.png)을 기준으로 컴팩트한 연속 목록을 구성한다. 브랜드 변경이나 밝은 테마 추가 시 같은 의미별 토큰을 유지하고 해당 테마 전체를 검수한다. 밝은 테마는 초기 필수 구현으로 간주하지 않는다.

상태색을 버튼 배경으로 사용할 때의 전경 조합은 실제 대비를 확인해 공통 variant로 정의한다. 밝은 강조 배경 위에 흰 글자를 일괄 사용하지 않는다. 보조 정보에 부모 opacity를 적용해 자식 전체의 대비를 낮추지 않는다. 선택 상태는 배경·경계와 접근성 상태를 함께 사용한다. 원시 색상을 페이지에 직접 추가하지 않는다.

자료 종류 아이콘은 글자 기호 대신 24×24 viewBox·1.75 선 두께·둥근 끝점의 SVG로 표시한다. 기본 크기는 18px이며 글자 색을 따른다. 설정에서는 아이콘과 이름을 함께 보여주는 단일 선택 라디오 묶음을 사용하고, 선택은 accent 테두리·배경 및 checked 상태로 구별한다. 선택 면의 아이콘은 24px, 최소 높이는 72px이며 가용 폭에 맞춰 줄바꿈한다. 키보드 초점은 선택 상태와 별도 outline으로 표시한다.

## 타이포그래피

기본 글꼴은 로컬 Pretendard 400/600과 한국어 시스템 fallback이다. public/fonts의 woff2는 Pretendard 1.3.9 시안 자산을 사용하고 SIL Open Font License를 함께 보존한다. 웹폰트 로딩 실패에도 읽을 수 있어야 한다. 배포 시 폰트 제공 방식·버전·라이선스를 확인한다. 루트 글자 크기는 축소하지 않고 rem과 유연한 줄 높이를 사용한다. 아래 값은 루트 16px일 때의 CSS px 환산값이다.

| 역할 | 크기 / 줄간격 | 굵기 |
| --- | --- | --- |
| page-title / dialog-title | 22 / 28, 20 / 28 | 600 |
| item-title | 14 / 20 | 600 |
| 현재 원칙 문서 제목 | 18 / 28 | 600 |
| section-title | 13 / 20 | 600 |
| value | 14 / 24 | 400 |
| summary-value | 24 / 32 | 600 |
| body / input | 14 / 24, 14 / 22 | 400 |
| 640px 미만 입력 | 16 / 24 | 400 |
| label / timeline-day | 13 / 20, 14 / 20 | 600 |
| action | 14 / 20 | 600 |
| body-action | 12 / 18 | 400 |
| secondary | 13 / 20 | 400 |
| meta | 12 / 18 | 400 |

같은 역할은 모바일·데스크톱에서 크기를 유지한다. 작은 화면의 입력만 16px로 두어 터치 입력 중 읽기와 모바일 브라우저 확대 동작을 고려한다. 본문 전체를 버튼 안에 넣었다는 이유로 action 스타일을 상속시키지 않는다. 글자 계층은 크기·굵기·간격으로 만들고 임의 자간이나 페이지별 크기를 추가하지 않는다. HTML 제목 의미와 시각 역할은 구분한다.

페이지·모달 제목과 데이터 제목은 기본 글자색으로 강조한다. 상세 본문의 데이터 제목은 20/28px·600으로 표시한다. 데이터 영역과 관계 영역은 1px line 경계와 24px 위 여백으로 나누며 관계가 없으면 경계도 생략한다. section-title은 데이터를 분류하는 작은 보조색 라벨이며 데이터 제목보다 강하게 표시하지 않는다. 본문은 body, 목록 미리보기·요약·오류·도움말은 secondary, 시각·보조 식별자는 meta다. 편집 폼의 보충 메모와 목록 미리보기는 14px·400·보조색으로 표시한다. 일반 보조 설명은 secondary의 13px이며 기록 원문은 body를 유지한다. 기록 상세에서는 변경 기록을 포함한 모든 기록 본문이 주 콘텐츠이므로 body 크기와 기본 글자색을 사용한다. 필수 안내와 삭제 영향은 작은 meta로 축소하지 않는다. 본문의 보조 행동은 body-action으로 왼쪽 제목·라벨보다 작고 가볍게 표시한다. 옅은 중립 면·보조색을 쓰고 작성·연결만 accent-soft·accent를 사용한다. 밑줄·테두리를 두지 않으며 키보드 초점은 조작 영역에 표시한다. 푸터의 보기·편집 및 섹션 하단의 저장·취소·변경 검토·적용은 기본 action 규격을 유지한다. 본문의 추가·제거·되돌리기·재조회·더 보기는 공통 BodyAction을 사용한다. 표시 면은 기본 24px 높이·12px/400 글자·12px 선 아이콘이며, 실제 조작 영역은 겹치지 않는 최소 44×44px을 확보한다. 추가는 accent-soft, 일반 보조 행동은 neutral-action-soft, 삭제는 danger 글자를 사용한다. 행의 위/아래 이동도 같은 작은 아이콘 면을 사용하고 제목과 펼침 표시에는 이 버튼 규격을 덮어쓰지 않는다.

긴 기록 본문은 body의 줄간격을 24px로 한다. 엔터티·할 일·기록의 읽기 속성은 공통 키–값 행으로 표시한다. 이름은 왼쪽 보조색 라벨, 값은 오른쪽 본문 글자로 정렬하며 좁은 화면에서도 같은 읽기 순서를 유지한다. 마크다운 제목은 18/28 또는 16/24·600으로 계층화한다. 코드 블록만 monospace 14/20을 허용하며 inline code와 링크는 주변 크기를 따른다. 일반 입력과 긴 한국어 본문 전체를 monospace로 표시하지 않는다.

숫자·시각은 tabular-nums를 사용하고 비교 열은 오른쪽 정렬한다. 단위와 값은 같은 크기로 읽히게 한다. 0과 미확정 값을 구분하며 정밀도·축약·시간대는 해당 기능의 계약을 따른다. 날짜 그룹과 표시 시각은 동일한 시간대 기준을 사용한다.

## 간격·곡률·크기

내용이 늘면 높이를 늘리고 고정 높이로 텍스트를 자르지 않는다. textarea는 최소 약 3줄에서 시작해 용도에 맞게 늘린다. 테두리는 기본 1px, 키보드 초점은 2px outline과 충분한 간격으로 표시한다. 상단 기능 구획은 페이지 바탕 위에 배치하며 중복된 안쪽 여백·외곽선·그림자를 두지 않는다. 펼친 필터·설정 입력 묶음은 panel 면·line 경계·8px 곡률·16px 여백으로 작업 범위를 구분한다. 모달 푸터는 input-surface 면과 상단 경계로 본문에서 구분하고 주요 버튼은 최소 88px 폭을 확보한다. 팝오버만 작은 공통 shadow-soft(0 8px 24px rgba(0,0,0,0.24))를 사용한다. 기록의 날짜 그룹은 timeline-day 제목과 여백으로 나누며 그룹 안의 목록은 옅은 surface 면으로 묶는다. 메인·연결 목록은 회색/강조색 2px 세로선을 항목 전체 높이에 같은 위치(왼쪽 8px, 상하 8px)로 표시한다. 회색은 marker-muted(#626c7b), 열린 행은 accent를 쓴다. 목록은 panel 면·line 경계·8px 곡률로 묶는다. 접힌 짧은 행은 52px로 읽히며 긴 제목은 자연스럽게 높이가 늘어난다. 행 사이는 옅은 1px 구분선을 두며 마지막 행은 생략한다. 열린 행은 surface 면을 사용한다. 확대/접힘 접근성 상태와 chevron으로도 구별한다. 원칙 현재 문서에는 목록용 세로선을 두지 않는다.

## 반응형과 레이아웃

100% 배율에서 폭 1280px 이상·높이 480px 이상(다른 배율에서는 두 기준에 배율을 곱한다)에서 열린 상세 작업 영역은 왼쪽 목록과 오른쪽 탭 패널의 두 열이다. 손잡이를 제외한 가용 폭에서 오른쪽 기본 비율은 46%이고, 목록 최소 28rem·상세 최소 27rem 안에서 조절한다. 가용 폭이 두 최소값을 감당하지 못하면 각각 가용 폭의 절반을 최소값으로 사용한다. 손잡이는 12px 폭의 조용한 경계 면과 중앙 3×32px 세로 선이며, 중앙 손잡이에 44×44px 누름 영역을 확보하되 위·아래 탭/푸터 조작을 가리지 않는다. hover·드래그·키보드 초점에서 강조색을 쓰고 초점 테두리를 표시한다. 좌우 방향키는 16px씩 조절한다. 목록·상세 크기 변경으로 폼을 다시 마운트하지 않으며, 목록·상세 본문은 각각 스크롤하고 상세 헤더·푸터는 고정한다. 전체를 감싸는 모달 배경·그림자는 두지 않고 패널 경계와 조절 손잡이만 표시한다. 탭은 13px 보조색 제목·16px 종류 아이콘과 최소 44px 조작 높이, 최대 15rem 폭의 말줄임을 사용한다. 선택한 탭만 panel 면·기본 글자색·하단 2px 강조선으로 구별한다. 탭이 많으면 탭 줄 내부에서 가로 스크롤하며 선택한 탭과 초점이 보이게 한다. 변경 확인창은 기존 중앙 모달 규격을 유지한다. 아래 640px 모달 기준은 탭 패널을 쓰지 않는 화면에 적용한다.

좁은 화면은 한 열을 기본으로 한다. 짧고 관련된 필드만 충분한 폭에서 두 열로 전환하며 긴 제목·본문은 전체 폭을 사용한다. 컨테이너와 flex/grid 자식은 줄어들 수 있게 하고 긴 URL·이름·태그는 줄바꿈한다.

640px는 일반 상세·편집 모달의 전체 화면/중앙 배치 전환 기준이다. 폭 1024px 이상·높이 320px 이상은 동일한 탐색 DOM을 왼쪽 13rem 사이드바로 배치하고 본문을 그 오른쪽에 둔다. 폭 또는 높이가 그 미만이면 하단 탐색이며 본문 끝에 탐색 높이와 safe-area를 확보한다. 본문 최대 폭은 72rem, 외곽 여백은 640px 미만 16px, 640–1023px 24px, 1024px 이상 32px이다. 기기명으로 기능을 제한하지 않는다.

데스크톱 표를 글자 축소로 모바일에 밀어 넣지 않는다. 일반 조회는 요약 행·카드·상세로 구성한다. 열 비교가 필수인 명시적 표 편집과 긴 코드·마크다운 표에만 내부 가로 스크롤을 허용한다. 페이지 전체 overflow 숨김을 해결책으로 쓰지 않는다.

Scrollbar chrome은 기본적으로 숨기고 wheel·키보드·터치·가로 스크롤 기능을 유지한다. 프로필 이모지 선택창은 두 줄 아래에도 선택지가 있음을 알리기 위해 얇은 세로 scrollbar를 표시하는 예외다. 선택창은 설정 입력과 같은 가용 폭을 사용하며 최소 56px의 자동 열로 채운다. 높이는 두 줄로 유지하고 넘치는 선택지만 내부에서 스크롤하며 색은 control-border/input-surface를 사용한다. 모달 본문의 장식 panel은 제거하며 입력·코드·표 경계는 유지한다. 엔터티·원칙도 활동처럼 상단 기능 패널과 하단 목록/현재 문서/이력을 별도 구획으로 배치한다.

필터 조작의 배치와 동작은 [컴포넌트와 상호작용](ui-patterns.md#필터와-목록)을 따른다. 검색 아이콘은 입력 왼쪽에 16px로 표시한다. 필터는 내부 구분선 없이 12px 간격의 공통 grid로 정렬한다. 768px 이상은 최대 네 열, 그 미만은 두 열, 320px 미만의 reflow는 한 열이다. 태그·범위 안내·기간 오류는 입력 grid 아래 전체 폭을 쓴다. 검색 label은 접근성을 유지하며 시각적으로 숨기고 placeholder를 사용한다. 조건 초기화는 검색어와 펼침 상태를 보존한다. 필터 조작 행은 작은 본문 행동의 24px 시각 면과 44px 누름 영역을 사용한다. 상단 기능 구획은 하단 20px 여백·1px line 구분선으로 목록과 나누며 중복된 내부 구분선을 만들지 않는다. 프로필 팝오버의 계정 이모지는 푸터/사이드바의 프로필 이모지와 같은 크기이며 큰 원형 장식을 두지 않는다. 프로필 팝오버의 행동은 같은 16px 아이콘과 44px 이상 행·8px/12px 안쪽 여백·공통 shadow-soft를 사용한다.

[필터 시안](references/compact-filter.png), [상세 시안](references/compact-detail.png), [확인 시안](references/compact-confirm.png)은 같은 톤의 시각 참고다. 이미지에 등장하는 예제 속성·명칭·태그·모바일 표시선 색은 제품 계약을 추가하지 않으며 실제 입력 항목과 기록 저장 동작은 현행 계약을 따른다.

## 목록 보기별 정렬

테이블의 머리글과 모든 행은 같은 가용 폭과 열 구성을 사용한다. 행 내부에 기록 wrapper가 있어도 제목 길이에 맞춰 폭이 줄어들지 않는다. 제목 열은 남는 폭, 종류·상태·날짜 비교 열은 80–128px의 안정된 폭을 사용한다. 숫자·시각은 같은 열에서 비교하며 좁은 화면에서도 페이지 가로 넘침이 없어야 한다. 카드의 제목은 최대 세 줄, 보조 값은 12px로 구분하고 같은 줄의 카드 높이를 강제로 늘리지 않는다.

기록 캘린더는 월과 선택한 날짜의 기록이 각각 22rem 이상을 확보할 때 두 열, 그보다 좁으면 한 열로 배치한다. 화면이 넓어도 글자 확대 등으로 본문 공간이 줄면 한 열로 전환한다. 월 제목은 16/24·600이며 월 구획은 목록과 같은 면·경계·곡률을 사용한다. 날짜는 가로 구분선으로 정렬하며 각 날짜의 조작 폭은 최소 44px, 높이는 좁은 화면 52px·640px 이상 64px다. 선택은 강조색 면·경계로 표시하고 오늘은 밑줄로 구별한다. 좁은 화면에서 일곱 날짜의 누름 영역을 유지하며 전체 페이지 가로 넘침을 만들지 않는다.

## 개인 화면 배율

모바일(화면 폭 1024px 미만)과 데스크톱(1024px 이상)의 배율을 각각 저장하고 현재 폭에 맞는 값을 적용한다. 화면 크기 구분은 배율과 독립적으로 판단해 경계에서 반복 전환하지 않는다.

화면 배율 100%가 이 문서의 기본 규격이다. 110%·125%·150%에서는 기기 기본 글자 크기에 선택 배율을 곱해 root 글자 크기를 정하고 rem 기반 글자·행간·공통 간격·보조 아이콘을 함께 키운다. 1px 테두리와 최소 44px 조작 영역은 유지하되 커진 내용에 따라 버튼/입력 높이가 늘어날 수 있다. 공간을 확보하려고 글자를 다시 줄이거나 가로 넘침을 숨기지 않는다. 배율 적용 후 두 패널을 읽기 어려운 폭이면 상세 모달을 사용하며 폼을 다시 마운트하지 않는다. 시스템 픽셀 해상도 변경이나 CSS transform/zoom으로 전체 viewport를 늘리는 기능이 아니다.

인증된 화면의 앱 브랜드는 데스크톱에서 아이콘과 Workspace 글자를 함께, 모바일에서는 현재 페이지 제목 옆 아이콘만 표시한다. 브랜드와 페이지 제목은 같은 제목 크기·28px 줄 높이와 32px 영역을 사용한다. 데스크톱 양쪽 제목 영역의 상단 여백은 32px, 제목에서 첫 탐색 메뉴 또는 검색창까지 간격은 16px로 맞춘다.
