# 시각 규격

## 적용 방식

이 문서는 [디자인 가이드](guide.md)의 시각적 기본값을 정의한다. 공통 스타일 한 곳에 토큰과 의미별 클래스를 만들고 각 화면이 사용한다. 값마다 별도 React 컴포넌트나 범용 스타일 엔진을 만들 필요는 없다. 변경은 공통 정의에서 하고 소비 화면을 검수한다.

## 테마와 색

기본안은 어두운 중립 배경과 하나의 강조색이다. 브랜드 변경이나 밝은 테마 추가 시 같은 의미별 토큰을 유지하고 해당 테마 전체를 검수한다. 밝은 테마는 초기 필수 구현으로 간주하지 않는다.

| 토큰 | 초기 기본값 | 역할 |
| --- | --- | --- |
| background | #0d0e12 → #14151a 세로 gradient + 좌상단 주황/우상단 청록 radial 14%/10% | 페이지 바탕 |
| panel | rgba(24,25,31,0.94) | 카드·모달 |
| surface | rgba(19,20,26,0.9) | 중립 보조 면·읽기 전용 필드 |
| input-surface | rgba(15,16,20,0.96) | 편집 필드 |
| ink | #ececef | 기본 글자 |
| muted-ink | #a0a4ad | 보조 글자 |
| line | rgba(255,255,255,0.1) | 장식 구분선 |
| control-border | #747985 | 입력·조작 식별에 필요한 경계 |
| accent | #ff8a00 | 대표 행동·선택·초점 |
| accent-ink | #15120d | 강조색 위의 글자 |
| accent-soft | rgba(255,138,0,0.16) | 선택 배경. 선택 테두리와 함께 사용 |
| danger / success / warning | #ff8c96 / #78dba9 / #f5c969 | 어두운 배경 위 상태 글자·아이콘 |

상태색을 버튼 배경으로 사용할 때의 전경 조합은 실제 대비를 확인해 공통 variant로 정의한다. 밝은 강조 배경 위에 흰 글자를 일괄 사용하지 않는다. 보조 정보에 부모 opacity를 적용해 자식 전체의 대비를 낮추지 않는다. 선택 상태는 배경·경계와 접근성 상태를 함께 사용한다. 원시 색상을 페이지에 직접 추가하지 않는다.

## 타이포그래피

기본 글꼴은 로컬 Pretendard 400/600과 한국어 시스템 fallback이다. public/fonts의 woff2는 Pretendard 1.3.9 시안 자산을 사용하고 SIL Open Font License를 함께 보존한다. 웹폰트 로딩 실패에도 읽을 수 있어야 한다. 배포 시 폰트 제공 방식·버전·라이선스를 확인한다. 루트 글자 크기는 축소하지 않고 rem과 유연한 줄 높이를 사용한다. 아래 값은 루트 16px일 때의 CSS px 환산값이다.

| 역할 | 크기 / 줄간격 | 굵기 |
| --- | --- | --- |
| page-title, dialog-title | 24 / 32 | 600 |
| item-title | 18 / 28 | 600 |
| section-title | 14 / 20 | 600 |
| value | 16 / 24 | 400 |
| summary-value | 24 / 32 | 600 |
| body, input | 16 / 24 | 400 |
| label, timeline-day | 14 / 20 | 600 |
| action | 14 / 20 | 600 |
| secondary | 14 / 20 | 400 |
| meta | 12 / 18 | 400 |

같은 역할은 모바일·데스크톱에서 크기를 유지한다. 본문 전체를 버튼 안에 넣었다는 이유로 action 스타일을 상속시키지 않는다. 글자 계층은 크기·굵기·간격으로 만들고 임의 자간이나 페이지별 크기를 추가하지 않는다. HTML 제목 의미와 시각 역할은 구분한다.

페이지·모달 제목과 데이터 제목은 기본 글자색으로 강조한다. section-title은 데이터를 분류하는 작은 보조색 라벨이며 데이터 제목보다 강하게 표시하지 않는다. 본문은 body, 목록 미리보기·요약·오류·도움말은 secondary, 시각·보조 식별자는 meta다. 편집 폼의 보충 메모와 목록 미리보기는 14px·400·보조색으로 표시한다. 기록 상세에서는 변경 기록을 포함한 모든 기록 본문이 주 콘텐츠이므로 body 크기와 기본 글자색을 사용한다. 필수 안내와 삭제 영향은 작은 meta로 축소하지 않는다. 보기·편집 같은 차분한 텍스트 조작은 action의 공통 modifier로 14/20·400, 밑줄과 보이는 초점을 사용한다.

긴 기록 본문은 body의 줄간격을 28px로 한다. 기록 상세의 사건 종류·출처·시각은 13px·400·보조색으로 묶어 본문과 구분한다. 마크다운 제목은 18/28 또는 16/24·600으로 계층화한다. 코드 블록만 monospace 14/20을 허용하며 inline code와 링크는 주변 크기를 따른다. 일반 입력과 긴 한국어 본문 전체를 monospace로 표시하지 않는다.

숫자·시각은 tabular-nums를 사용하고 비교 열은 오른쪽 정렬한다. 단위와 값은 같은 크기로 읽히게 한다. 0과 미확정 값을 구분하며 정밀도·축약·시간대는 해당 기능의 계약을 따른다. 날짜 그룹과 표시 시각은 동일한 시간대 기준을 사용한다.

## 간격·곡률·크기

| 항목 | 기본값 |
| --- | --- |
| 간격 단계 | 4 / 8 / 12 / 16 / 20 / 24 / 32px |
| 카드·기본 버튼 곡률 | 16px |
| 입력 곡률 / 칩 곡률 | 12px / 10px |
| 카드·모달 본문 여백 | 640px 미만 16px, 이상 24px |
| 모달 header/footer 좌우 여백 | 본문과 동일하게 640px 미만 16px, 이상 24px |
| 할 일 행 좌우 여백 | 12px |
| 라벨→필드 / 제목→보조 정보 | 8px |
| 필드 묶음 / 의미가 다른 섹션 | 16px / 24px |
| 상단 패널→본문 | 20px |
| 칩 가로·세로 간격 | 8px |
| 입력 높이 / 좌우 여백 | 최소 48px / 12px |
| 버튼·선택 칩·아이콘 조작 | 최소 44×44px |
| 읽기 전용 칩 | 최소 높이 28px. 조작 없음 |
| 일반 모달의 넓은 화면 최대 폭 | 42rem |

내용이 늘면 높이를 늘리고 고정 높이로 텍스트를 자르지 않는다. textarea는 최소 약 3줄에서 시작해 용도에 맞게 늘린다. 테두리는 기본 1px, 키보드 초점은 2px outline과 충분한 간격으로 표시한다. 상단 패널은 공통 shadow-soft(0 28px 60px rgba(0,0,0,0.32))를 사용하며 내부 행마다 중첩하지 않는다. 기록의 날짜 그룹은 timeline-day 제목과 여백으로 나누며 그룹 안의 목록은 옅은 surface 면으로 묶는다. 메인·연결 목록은 회색/강조색 세로선을 항목 전체 높이에 같은 위치·두께로 표시하고 행별 가로 구분선·외곽 테두리를 두지 않는다. 원칙 현재 문서에는 목록용 세로선을 두지 않는다.

## 반응형과 레이아웃

좁은 화면은 한 열을 기본으로 한다. 짧고 관련된 필드만 충분한 폭에서 두 열로 전환하며 긴 제목·본문은 전체 폭을 사용한다. 컨테이너와 flex/grid 자식은 줄어들 수 있게 하고 긴 URL·이름·태그는 줄바꿈한다.

640px는 일반 편집 모달의 전체 화면/중앙 배치 전환 기준이다. 1024px 이상에서는 실제 읽기 필요가 있는 상세 드로어를 예외로 검토할 수 있다. 기기명으로 기능을 제한하지 않는다. 페이지 shell과 하단 탐색은 최대 72rem이다. 외곽 여백은 640px 미만 16px, 이상 24px이며 상단 20px·본문 끝은 탐색 높이와 safe-area를 확보한다.

데스크톱 표를 글자 축소로 모바일에 밀어 넣지 않는다. 일반 조회는 요약 행·카드·상세로 구성한다. 열 비교가 필수인 명시적 표 편집과 긴 코드·마크다운 표에만 내부 가로 스크롤을 허용한다. 페이지 전체 overflow 숨김을 해결책으로 쓰지 않는다.

Scrollbar chrome은 모든 영역에서 숨기고 wheel·키보드·터치·가로 스크롤 기능을 유지한다. 모달 본문의 장식 panel은 제거하며 입력·코드·표 경계는 유지한다. 엔터티·원칙도 활동처럼 상단 기능 패널과 하단 목록/현재 문서/이력을 별도 구획으로 배치한다.
